## 可复现的失败与修复

### 整行引文不应被当作无效金额

原五粮液失败会话中，LLM 返回整行作为证据，再单独选择 `raw_value`。旧实现把整段引用交给单值解析，产生重复 `AMOUNT_NOT_EXPLICIT`，不是搜不到资料。

只读复制该会话的23次提取调用，在临时数据库回放：通过 schema 的198行提交中139次保存成功，137个不同观察证明；重复提交也计入其中，不代表137个不同财务字段。其余包含5次 schema 失败、36项引文定位错误及23项分段错误。该回放没有新的 LLM 解释、语义复核、交叉核对或估值，不能当作最终字段全部可用。

新契约允许整行/多行引用，由 LLM 选择金额，程序核验完整数值并保存字符位置；重复同值必须指定出现位置。错误返回真实选中原文和候选定位，不自动替模型选择列或保存数据。

### 文件解码与财务理解分开

实际瑞芯微 PDF 第7页中，pypdf 的两种文本视图把两个营业收入列拼为 `4,402,090,888.243,136,370,678.42`。新增 `pdf_geometry` 通过字符坐标恢复为两个独立数值，保留文件哈希、页码、解码器版本与参数。

这只是通用文件阅读能力，不由代码判断哪个金额属于哪年。PDF页面选择、主体、年度、单位、合并/母公司口径及字段语义仍由 LLM 阅读并复核。纯扫描件 OCR 和独立视觉转录复核仍未闭合。

### 减少无效往返，而非取消财务约束

- 原始行号引用可省略 `quote`，避免模型重抄空格；显式引文仍严格匹配。
- 一次模型回复最多6项工具调用，顺序执行；同一复核批次共享完整原文上下文，不重复占用包预算。
- 普通披露收入、利润、税费与股数不再统一要求经营/融资角色；现金、债务、FCFF、利息和金融子公司处理保留约束。
- 连续阅读只增加非阻断提示，鼓励先保存、复核已有核心数据；重复错误仍有有界保护，不允许靠无限付费轮询完成任务。

## 历史删除

- Web 侧栏删除按钮需二次确认，明确不可撤销及保留文件范围。
- 后端校验当前修订、活动任务及独占计算归属，在单个 SQLite 事务中删除所属记录。
- 排队/运行任务、活动租约及共享计算阻止删除；迟到的写入不能重新创建已删工作区。
- 删除当前对话清空任务局部状态；删除其他对话保留当前对话；迟到的读取响应不会把已删除任务显示回来。
- 保留可能共享的原始文件库字节及用户电脑上已导出的文件。没有删除任何真实用户会话。
