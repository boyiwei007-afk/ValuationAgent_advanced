# 生产缺口修正记录：2026-10-01，.13

结论：本轮包含通用缺陷修正，不含公司名称特判；**没有宣布任意非金融 A 股估值已经通过生产验收**。

## 修正内容

1. 可比分母不再仅靠直接找到研报中的 FY 倍数。主 LLM 可以分别读取同日发行人总市值、与目标基期一致的年度合并收入/归母净利润。程序以 Decimal 推导 PE/PS，保存公式及分子、分母的原始证据，不生成伪造的“直接披露倍数”事实。日期、单位、币种、范围、冲突、负分母、目标公司自比及不同 FY 均有检查。
2. 直接披露倍数要求 `denominator_period_end` 及原文依据；缺少分母年份的旧输入不静默兼容。工作台样本就绪状态按实际可计算样本统计，不能仅凭三个公司代码算完成。
3. 端到端合成回归发现两个隐藏的交接问题：纯相对估值把 `ResolvedAssumptions.wacc=0` 写进只允许正 WACC 的输入契约，以及空假设被错误标记为手工假设。现在只为 DCF 冻结其预测/折现驱动，PE/PS 不再需要填写无关 WACC，也不借此关闭 DCF 的约束。
4. `begin_file_task/end_file_task` 在同一 LLM、同一总时间/调用预算内建立最多 16 步的单文件阅读阶段。主模型自行选择检索、视图、提取与复核；限制由执行器检查，不只是提示语。完成后回到原对话。隔离其他文件及旧错误叙述，但不赋予新的检索、计算或改任务权限。
5. `read_file(block_id=...)` 支持直接读已存块；行窗口保留原始编号和续读位置，不把块后缀当 PDF 页码、不改写持久原文。复核包在主历史压缩前选择，避免先删掉正文再宣称完成隔离复核。
6. JSON 网关传递数组、字符串和对象数量上限；本地仍执行完整 Pydantic 校验，截断输出仍不执行。已用真实网关的小范围 schema 探针验证长度/数量限制，后续 22 次真实调用没有再次输出截断，但这不证明语义正确或后续所有调用不截断。[SGLang 结构化输出文档](https://github.com/sgl-project/sgl-project.github.io/blob/main/markdown/advanced_features/structured_outputs.md)与[XGrammar JSON schema API](https://xgrammar.mlc.ai/docs/latest/api/python/grammar.html)说明的是结构约束，不保证金融解释准确。
7. 单操作者登录、Host/Origin 检查、默认回环访问、HTTPS 远程要求和退出功能见[部署边界](DEPLOYMENT_READINESS.md)。CLI 欢迎页、Web 工作区与已有历史删除交互保留。
8. 模型断连和测试预算结束也更新当前检查点，避免显示上一轮的旧截断原因；自动估值的批准事件标记 `automatic_policy`，不再写成用户人工确认。
