## 日常启动

首次安装或依赖变化才需要安装 Python 包和 `npm ci`；前端源码变化后需要 `npm.cmd --prefix web run build`。日常只需：

```powershell
conda activate economic_agent
valuationagent
# 或启动 Web
valuationagent serve
```

在页面或 CLI 内配置模型和搜索服务。配置仅保存在进程内，重启后重新连接；工作区、原文和计算记录保留。`.env.example` 是环境变量模板，不是自动加载或保存密钥的配置文件。

## 访问边界

- 不设置 `VALUATION_ACCESS_TOKEN`：仅允许本机访问。即使绕过 CLI 用其他 ASGI 启动方式监听外网，非回环客户端仍不能读取工作区。
- 配置唯一、随机、至少 32 字符的 `VALUATION_ACCESS_TOKEN` 后启用访问保护。它不是模型 API Key，更不是 SSH 密码，不写入仓库或工作区。
- 浏览器首页登录后使用 HttpOnly、SameSite=Strict、8 小时有效的随机会话 Cookie；HTTPS 下同时设置 Secure。Cookie 只对应内存会话，服务重启或“退出访问”后失效。访问凭证本身不放入 Cookie、本地存储或 URL。
- 自动化客户端可以发送 `Authorization: Bearer <工作区访问凭证>`；查询参数中的凭证无效。退出浏览器不会撤销管理员的 Bearer 凭证。
- API、来源、报告、上传、历史删除、模型配置和文档页均受同一访问边界保护。`/health` 仅用于公开存活探测，健康不代表模型在线或估值正确。
- 写入请求检查 Origin，Host 使用显式白名单。登录按客户端地址限流；共享代理后应同时配置代理层限流。

**这是单操作者空间**：持有凭证者共享所有研究资料，不是账户系统，没有租户隔离和分角色授权。不要把同一个凭证分发给彼此不应访问资料的用户。CLI 拥有本地文件权限，不受 HTTP 登录约束。

## 受保护部署

1. 使用 HTTPS 反向代理，后端保持 `127.0.0.1:8000`；防火墙禁止直接访问后端端口。
2. 在服务进程环境注入 `VALUATION_ACCESS_TOKEN`，不要在命令行参数、URL、版本控制或脚本中写真实凭证。
3. 设置 `VALUATION_ALLOWED_HOSTS` 为实际域名及需要的回环主机名，逗号分隔；拒绝裸 `*`。生产环境不需要默认开发站点时，显式设置 `VALUATION_CORS_ORIGINS`。
4. 只信任已知反向代理的 forwarded headers，不能信任任意来源的 `X-Forwarded-*`。远程客户端的非 HTTPS 请求会被拒绝。
5. 当前使用单个服务进程。模型连接与浏览器登录会话在内存中，不支持直接增加多个 Uvicorn worker 来扩容。
6. 重启代码后核对 `/health` 的 `agent_version`；分别验证无凭证被拒、登录成功、退出后拒绝、来源及下载受保护。TLS、代理超时、真实浏览器布局和负载必须在部署现场验收。

运行中的任务退出登录后不会自动取消；先使用工作台“暂停”才能中止执行。不要误把关闭页面当成任务取消。

| 门槛 | 当前边界 |
| --- | --- |
| 非金融 A 股多行业全新会话：检索→原文理解→数值估值→报告 | 未通过；真实测试仍有股数解释和可比取证停滞 |
| Tushare数据 + 用户明确指定PE → 计算 → PDF → 离线复算 | `.25` 苏泊尔、瑞芯微、五粮液限定测试通过；不是自主选倍数、DCF或PDF/Excel提取验收，也不是发行人原始披露独立验证 |
| 独立金标准核对金额、单位、主体、年度、股份时点及来源 | 未完成多行业覆盖；增加基于原始页图的少量独立案例及只读审计脚本，不给Agent注入答案。实际发现同一股数位置被赋给两个年度且自我复核放行，新增源位置冲突阻断及续做前降级；不是完整语义审计 |
| PE/PS 的已准入事实→冻结→计算→报告→敏感性→复算 | 有明确合成数据的端到端回归；不是现实公司准确率验收 |
| 自动策略与人工批准区分 | 检查点及事件记录批准主体；自动模式仍是草案 |
| 自由追问、禁止联网/重算、用户敏感性指令 | 有回归和部分真实交互测试；金融问答语义质量尚未完成验收 |
| 历史删除、并发保护、失败保存、来源哈希 | 有自动化回归；不会为“完成”而零填缺失数据 |
| 访问控制 | 单操作者边界，不是多租户授权；公网服务还需身份、租户、配额和运维体系 |
| 文件执行风险 | 不向 Agent 开放任意宿主机命令；进程级解析隔离、强制资源限额和扫描件闭环仍待完成 |
| 恢复与运维 | 尚缺目标环境备份恢复演练、故障注入、容量和长稳测试；不能以健康接口替代 |

正式发布前应固定模型 ID、推理配置、代码/参数版本及测试数据集，用未参与调试的公司重复验收。结果应分别标记“数值正确”“来源元数据正确”“不支持且正确拒绝”“执行停滞”，不能仅统计 confirmed 数量或测试通过数。

`live_document_acceptance.py` 未达到数值闭环时退出码为1。通过条件包括非演示数值计算、同版本数值报告、报告哈希完整性、冻结输入离线复算与执行无失败；通过仍须独立原文审计和未见公司的泛化测试，不能据此自动宣布生产发布。

相对估值默认采用估值日行情。显式设置 `peer_pricing_date` 和 `peer_pricing_rationale` 后可采用此前七天内的统一可核验行情日，与计算器既有时效限制一致；不会自动识别交易日或修改原文日期。估值日及信息截止日不变，所有可比须同日，日期差和理由随可比样本冻结。

真实验收脚本记录源码与配置文件摘要；运行期间代码改变则 `source_revision_stable=false`，不能通过验收。它不替代依赖环境固化、原始来源审计和独立公司测试。
