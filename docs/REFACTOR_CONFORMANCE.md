- 估值前后同一工具循环、同一消息历史、同一模型连接。
- 删除旧研究 API、CLI 向导、规则意图路由、确认卡协议、结果聊天路由及旧网页组件。
- 删除 runner 的第二套 LLM 审核循环、旧兼容开关、专属脚本、过时报告和终端预览资源。
- CLI 直接 valuationagent 启动，终端内配置模型/搜索、上传附件、继续工作区；Web 与 CLI 不分叉 Agent 实现。
- 默认自动草案，保留显式方案审批。
- 初次及修改后的计算均在执行前冻结输入；缺少 ModelSpec 不事后补造。

- GET 工作区快照只读。
- 比较公司事实不互相冲突；高风险不通过披露自动消除。
- 初始与工具轮次上下文有字符预算，保留工具协议配对。
- 原文下钻、任务计划和只读计算历史。
- 选择卡片与自由输入共用普通消息路径，不恢复旧确认卡协议。
- 按年份、报告类型与主体分配检索目标，保存预算/无进展续做检查点；不会自动无限续跑。
- 确定性年度覆盖与字段字典，原文重检修复；支持官方中报/季报目录。
- CLI 参考备份视觉风格重写欢迎页、对话、配置和实时流程工作台，保持统一 Agent。
