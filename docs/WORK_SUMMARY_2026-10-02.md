# ValuationAgent 工作总结

**日期**：2026-10-02  
**仓库**：`boyiwei007-afk/ValuationAgent_advanced`  
**当前引擎版本**：`workspace-agent-2026-10-02.15`

## 1. 项目目标

ValuationAgent 面向非金融 A 股公司的自动化估值，目标是对标 coding agent 的交互方式：

- 支持自由对话、任务补充、方案选择和继续执行。
- 支持联网检索、用户上传文件和本地文件工作区。
- 由 LLM 理解年报、公告、PDF 表格和网页原文，提取财务事实。
- 使用确定性计算器完成 PE、PS、DCF、EV/EBITDA、敏感性分析。
- 每个结论可追溯到来源、原文定位、期间、口径和计算输入。
- 同步支持 Web 工作台和 CLI，保留欢迎页、对话体验和流程可视化。

## 2. 本阶段已完成

### 2.1 架构与交互

- 统一工作区模型，Web 与 CLI 共享任务、证据、计算、报告和历史会话状态。
- 新增工作台、进度阶段、事实账本、风险提示、敏感性分析和报告导出。
- 支持历史估值对话的查询和删除。
- 保留 `valuationagent`、`valuationagent chat`、`valuationagent serve` 日常入口，不再依赖旧版向导。
- 删除旧 interactive/wizard/research 等重复路径，避免新旧逻辑混用。

### 2.2 LLM 优先的文档理解

- 主链路为 `extract_observations → prepare_observation_review → review_observations`。
- LLM 负责理解原文语义、表头、期间、币种、单位、合并/母公司口径和会计含义。
- 程序只承担安全边界：原文定位、数值完整性、单位换算、来源一致性、期间回读和模型准入。
- 支持同一份年报中的多年度比较列，不再把“下载文件”误认为“已完成年度取证”。
- 支持 `7.71亿元`、`799,882,879股`、`12倍` 等显式单位后缀，并拒绝单位不匹配、区间值和模糊近似值。
- 读取失败优先在当前来源内切换页码、行窗口、原文视图或搜索定位，不再无条件重复下载。
- 对即时事实增加来源期间回读闸门，防止把回购完成日、公告日误当成年末数据日。

### 2.3 研究计划与估值模型

- 自动生成年度数据采集目标，区分估值基期、历史趋势、股本时效和可比公司数据。
- 对 DCF、PE、PS、EV/EBITDA 分别检查所需输入，不再用统一门槛阻塞所有方法。
- 计算由确定性金融模块执行，模型不能直接输出未经验证的估值数字。
- 支持方法选择、用户补充参数、情景假设、WACC、永续增长和敏感性分析。
- 财务公司、受限现金、金融子公司等特殊口径保留桥接风险，不强行套用普通非金融公式。

### 2.4 证据、复现与报告

- 记录来源 URL、来源级别、文件哈希、下载快照、原文页码/行窗口和观察值状态。
- 区分候选、已绑定、已复核、已确认、被拒绝和需人工复核状态。
- 报告明确区分事实、推导、假设、风险和未完成项。
- 支持冻结复算包、审计脚本、观察值回放和来源风险交接。
- 新增独立来源审计夹具，用于发现 LLM 期间语义误判，而不是只测试代码格式。

### 2.5 远程模型

- 已接入远程 OpenAI 兼容服务，当前实际模型 ID 为 `qwen36-teacher`。
- 本地通过 SSH 隧道调用，API 兼容 `OpenAI(base_url="http://127.0.0.1:18000/v1", api_key="EMPTY")`。
- 模型密钥仅通过环境变量/运行时配置使用，不写入仓库或工作区数据库。
- Qwen 工具协议改为轻量 `{name, parameters}` 信封，仍由本地工具注册表和 Pydantic 参数模型做严格校验。

## 3. 测试与真实验收结果

### 3.1 工程回归

最近一次完整 Python 回归记录为 **989 passed、1 warning**。已覆盖：

- 工作区、CLI、Web API 和历史删除。
- 文件读取窗口、搜索、上传、恢复和安全边界。
- 单位解析、观察值抽取、期间一致性和来源审计。
- PE/PS/DCF 输入准备、可比公司输入、敏感性分析和报告合同。
- LLM 工具协议、上下文预算和异常恢复。

工程回归通过只代表代码契约稳定，不代表任意公司都已完成准确估值。

### 3.2 真实模型验收

- 老板电器测试：模型能够进入取证流程，但曾因估值日期缺失或重复读取而停滞。
- 海康威视测试：从官方年报提取并确认 2025/2024 年收入、归母净利润和一项股本事实，共 5 项确认事实。
- 海康威视测试仍未稳定完成可比公司采集、估值计算、敏感性分析和正式报告。
- 独立 PDF 视觉审计发现股本“回购完成日”与“年末股本日”的语义混淆；新增期间回读闸门后，该类事实会被阻断而不是错误入模。

## 4. 当前结论

当前版本已经具备完整的研发级流程和较强的证据安全边界：

- **可以**进行单用户、有人监督的研究试用。
- **可以**读取用户文件或检索到的文件，并展示逐步证据状态。
- **可以**在输入完整且通过准入后进行确定性估值和报告生成。
- **尚不能**宣称对任意非金融 A 股无人值守完成估值。
- **尚不能**直接作为公开、多租户、无人工复核的生产服务。

当前最大的风险已经从“静态解析经常卡死”转移为“真实模型在多轮检索和可比公司采集阶段可能重复或停止”。系统现在会安全停下并报告缺口，不会编造价格，但仍需继续提高自动推进能力。

## 5. 投产前剩余工作

1. 建立 10 家以上未见公司的端到端验收集，覆盖半导体、消费、医药、制造、软件等行业。
2. 强化可比公司发现、报价/市值/股数期间对齐和 PE/PS 输入闭环。
3. 增加“重复读取检测、无进展计数、替代工具策略、阶段性决策”机制，减少模型循环。
4. 在真实模型上完成：财务取证 → 可比采集 → DCF/相对估值 → 敏感性 → 报告 → 冻结复算。
5. 为关键事实引入第二来源或独立审计规则；同一 LLM 的复核只能作为复核，不视为独立审计。
6. 完成生产部署的进程隔离、上传文件安全扫描、备份恢复、限额、日志脱敏和长时间稳定性测试。
7. 通过真实验收门槛后，再发布生产版本和对外部署文档。
