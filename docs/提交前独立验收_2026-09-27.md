# 提交前独立验收（2026-09-27，v14）

## 结论

当前版本可作为**生产候选版和竞赛演示版**，但尚不能签字认定为“生产级自动估值”或保证任何奖项。安全兜底、可追溯报告和合成算术验收通过；真实公司在无需逐字段确认的端到端流程中，仍没有一例完成可核查的数值估值。不能把“生成数据不足报告”计为数值估值成功。

## 本轮修正

- 永续增长率为0不再被替换为3%；负增长率按`g/ROIC`参与终值再投资，不再隐式截为0。Excel的终值和敏感性公式与计算器同口径。
- 亏损预测年不自动假设立即获得所得税退税；未建模可结转亏损时，NOPAT按非负应税EBIT计当期税。
- WACC资本权重与股权价值桥接使用同一套资本化租赁债务；债务是否含租赁不明时扩大估值区间并降质量，不静默选择有利值。
- Tushare自动同业P/E、P/S由同日市值和同期FY利润/收入复算；不再把其TTM倍数与目标FY财务混用。缺少同行完整EV桥接时不自动生成EV/EBITDA。Tushare官方`daily_basic`字段定义明确将`pe_ttm`、`ps_ttm`标为TTM：[接口文档](https://tushare.pro/document/2?doc_id=32)。
- 年报中“截至具体日期，公司总股本……股”的校验结果现可进入最新每股估值分母；旧的组装逻辑只认相对的“截至报告披露之日”标签，导致伊利已核验股数被误报为缺失。新增回归测试覆盖正确接入及日期证据缺失时拒绝接入。
- 年报中的少数股东权益账面值代理是**质量警告**，不再当成与模型不相容的硬阻断；受限现金、同业存款和金融性子公司等未解决的特殊桥接仍不得填零。
- 约284px窄屏的顶部导航溢出已修复，并在实际浏览器窗口重新目视检查；该项不是自动化视觉回归。

## 真实案例与原因

验收来源为巨潮资讯的[伊利股份2024年年度报告](https://static.cninfo.com.cn/finalpage/2025-04-30/1223421123.PDF)，本地来源SHA-256为`a82a81e52f52da3cd1b7f38ded08625dc18e3d4522b15d3ef76bf921e54c1f43`。测试截止日为2025-06-30。第三次连续研究记录：35个候选、其中27个无取证警告、6个尚有警告，累计1次官方公告检索，35.33秒；交付了有校验ID的说明报告，但未交付数值价格区间。该测试没有自动批准真实财务事实，符合集中复核边界。对应机器可读记录：`var/real-company-20260926/v13-share-recheck-20260927/600887/acceptance.json`。

股数修复后用同一持久化研究会话离线重建预览，`2025-04-08`的已核验总股本能进入`2024-12-31`基期快照；剩余核心缺口变为有息债务，而非股数。伊利年报另披露债券、短期融资券、受限资金、财务公司相关项目；直接用少数债务行相加或把空白债券余额当零，可能低估债务/高估可分配现金。系统目前选择不出数值，方向上比虚构估值更安全，但自动完成率仍不足。

早期多公司/零上传测试曾发生模型供应商`HTTP 402`余额不足，相关未完成结果不可用来判断纯代码成功率。本轮余额恢复后伊利案例仍未出数值，因此不能以历史`402`解释全部未通过项。Tavily和Tushare的真实生产权限、限额与稳定性尚未在本轮重新验收；官方公告检索成功不等于所有联网来源通过。

## 提交建议与未关闭的P0/P1

1. **P0：真实数值闭环。** 选至少3家经营相对简单的非金融公司，分别用零上传与上传资料，在明确的估值日复跑；每家公司需达到“来源核验→集中复核→数值DCF或至少一种可比估值→敏感性→PDF/Excel/JSON”，并由金融小组对账。复杂集团即使安全拒绝，也不能替代这些成功样本。
2. **P0：金融金标准。** 对同一来源和估值日固定收入、EBIT、税、D&A、CapEx、营运资本、债务、现金、股数与WACC，逐格比对基期勾稽、FCFF、终值、权益桥接和WACC×g矩阵；记录允许误差与复核人。
3. **P1：正式环境稳定性。** 记录模型/搜索权限、限流、超时、成本、并发和恢复测试；选择现场可用的离线或半封闭资料包。扫描版年报目前没有内置OCR，需声明限制或补充可复现能力。
4. **P1：复杂金融资产/负债。** 对财务公司、受限现金、大额存单、短融/债券、少数股东权益和租赁建立行业/公司适用的专项桥接，或明确排除该方法；不要为提高出数率而削弱门禁。

演示时应把“安全出说明报告”与“成功算出经复核估值”分别展示。正式提交材料应保留源代码、依赖、第三方许可、来源哈希、工具事件和完整复算记录，并由金融小组签字确认至少一个真实公司数值案例。
